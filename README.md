# CypherAlgorithms
Algoritmos de cifrado para la clase de cifrado. 


## Cifrados históricos
[Cifrados Históricos](./historical_cyphers/)

### Descripción:

Los cifrados históricos constituyen la base conceptual de la criptografía moderna. Aunque hoy en día no se utilizan para proteger información real, su estudio permite comprender principios fundamentales como:
- Representación de la información

- Transformaciones reversibles

- Confusión y difusión

- Ataques criptográficos básicos

En este ejercicio, nos enfocaremos a generar scripts criptográficos utilizando las funciones de nuestro ejercicio de criptografía.<br>

Restricciones:<br>

No se permite el uso directo de
- Librerías criptográficas
- Funciones nativas de cifrado
- Funciones de conversión externas

Algoritmos a implementar: 
- César
- Rot13
- Vigenere
- Análisis de frecuencia
